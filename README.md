# 京都雪庭 · 雪見私湯

一座可以旋转、缩放、平移的 Three.js 二次元微缩雪庭：温润木构雪庵、厚雪青灰瓦、室内茶席与暖炉，前庭是一方以粗石围合的露天私汤。背景以染色和纸、淡折屏、偏右的巨型圆窗、淡雪林剪影与半透明布帘构成一座“舞台”。

## 运行

无需构建，直接起一个静态服务器：

```bash
cd Kyoto-Snow-Pavilion
python -m http.server 5173
```

打开 <http://127.0.0.1:5173/>。Three.js r160 已放在 `vendor/`，页面不依赖外网。

## 操作

- **拖拽**旋转，**滚轮**缩放，**右键/双指**平移。
- 点击 **树枝**：振落枝头积雪。
- 点击 **雪地**：留下成对足印，并扬起一点雪粉。
- 点击 **温泉水面**：进入贴近水面的泡汤视角；再点水面可添一圈涟漪，点 “离池返回” 或按 `Esc` 回到庭院。
- 点击 **室内暖炉**：抛入一根柴，火舌腾起、火星四散。
- 点击 **障子门**：推开或合上。
- 底部时间条：朝雪 07:00 / 暮色 18:00 / 雪夜 22:00，或拖动滑杆在 24 小时里漫游。灯光、和纸、圆窗、水面与雪雾会一起过渡。

## 场景构成

- **建筑**：歇山式青灰瓦顶与厚雪毯，梁柱、檐下椽木、缘侧、可开合障子、暖纸提灯；室内有榻榻米、蓝染被炉与茶点、雪景挂轴、书架陶器、悬挂浴衣、阅读椅和燃烧的囲炉裏。
- **庭院**：11 株高大雪树与 4 株低松错落半包围；树枝横展、细梢垂坠，厚雪包覆并露出树皮。前庭温泉以不规则粗石围合，内侧湿石、外侧厚雪；竹筒注水、水花、涟漪、暖光倒影与局部汤雾。踏石连接木廊，另有覆雪矮木灯、木桶毛巾与茶点托盘。
- **舞台**：一整圈高耸的染色和纸圆柱背景环绕庭院，左右均可环视；低位折屏、偏右巨型圆窗、淡雪林剪影与两侧半透明布帘置于后方。轻颗粒与暗角由 CSS 完成。
- **时间**：灰青晨光、金橙侧光与蓝紫雪影、墨蓝月色与暖屋灯火；飘雪分远中近三层。

所有几何、材质与贴图均由代码程序化生成（木纹、和纸、榻榻米、瓦片、蓝染、挂轴、折屏、窗景、火焰、雪片、足印等），没有外部图片或模型。
